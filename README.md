# mithor-privacy

Política de privacidad pública de **MITHOR**, el control de brillo para Windows.

- Publicada en GitHub Pages: <https://tony-toaf86.github.io/mithor-privacy/>
- Se enlaza desde la aplicación (**Ajustes → Privacidad**) y desde el instalador.
- El código de MITHOR está en <https://github.com/Tony-Toaf86/MITHOR-PROGRAM>.

## Contenido

- `index.html` — la página completa, en español, con un resumen en inglés al final.
  Es un único archivo autocontenido: sin JavaScript, sin CSS externo, sin fuentes ni imágenes
  remotas y sin cookies.

## Publicación

El repositorio sirve la rama configurada en **Settings → Pages** (normalmente `main`, carpeta `/root`).
Cualquier cambio en `index.html` se publica automáticamente en un par de minutos.

Para publicar desde otra rama o carpeta, cámbialo en esa misma pantalla.

## Cómo modificar la política

1. Edita `index.html`.
2. Actualiza la fecha de «Última actualización» en el encabezado y en el pie.
3. Si el cambio es relevante, anúncialo en el repositorio de MITHOR.

La política debe seguir siendo exacta: si algún día MITHOR añade telemetría, actualizaciones
automáticas o cualquier conexión de red, **esta página tiene que reflejarlo antes** de publicar esa
versión.
